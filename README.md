### 💡 ¿Qué es *pwaexe*?

**pwaexe** convierte cualquier sitio web en una aplicación ejecutable de Windows usando **WebView2**.  
Ideal para quienes prefieren aplicaciones ligeras en vez de usar el navegador o instalar apps nativas pesadas.

Actualmente incluye una versión de **Gemini** y se espera ir sumando:

- 🧠 ChatGPT
- 📺 YouTube
- 🔍 Google
- 🔎 Bing  
...y muchos más.

### 🚀 ¿Por qué usar *pwaexe*?

- ✅ Ejecutables independientes sin navegador
- 💾 Ultra ligero y sin instalación compleja
- 🧩 Alternativas a apps web o apps nativas
- 🎯 Ideal para entornos limitados o específicos

### ⚙️ Requisitos

- Windows 10/11  
- WebView2 Runtime (se instala automáticamente en la mayoría de sistemas)

### 🛠️ Tecnologías

- C# con WinForms
- Microsoft WebView2
- Proyectos individuales para cada webapp
